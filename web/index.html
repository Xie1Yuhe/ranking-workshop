使用说明

排名：把左侧内容池的卡片拖到任意赛道；赛道内拖动可以调整顺序。

详情：单击卡片打开详情，可改名、写点评、切换赛道；方向键切换同赛道上一项 / 下一项。

改名：双击卡片名称或赛道名称即可直接修改。

快捷键：Ctrl+S 导出图片 · Ctrl+F 搜索 · N 演示模式下召唤下一张 · Esc 关闭弹窗 / 退出演示 · Ctrl+V 粘贴截图

数据：改动自动写入程序目录 data\state.json；换电脑时复制该文件，或用「导出 JSON / 导入 JSON」搬移。
